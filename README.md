# Copilot Project Submission

## Project overview
This submission demonstrates a simulated Microsoft 365 Copilot workflow for identifying and responding to critical pharmaceutical supply-chain issues affecting production continuity and regulatory compliance.

## Files and purpose

### Prompt_Library
- `Copilot Prompt Library.docx`: Full prompts, names, applications, and purposes for Tasks 1–4.

### Task1
- `Email Summary.docx`: Email analysis with critical issues and five next steps.
- `Supply Chain Issues Review.docx`: Professional review report with introduction, business problem, action items, and conclusion.

### Task2
- `Meeting Invitation and Agenda.docx`: Simulated invitation with stakeholders, timed agenda, and expected decisions.
- `Action Plan.docx`: General, immediate, short-term, and ongoing actions.

### Task3
- `Supply Chain Issue Analysis Report.docx`: Executive risk assessment, supplier analysis, compliance impact, root causes, and mitigation strategies.

### Task4
- `Supply Chain Issue Compliance Report.pptx`: Stakeholder presentation with speaker notes and data visualizations.

### Supporting_Files
- `Supply Chain Analysis.xlsx`: Recreated analysis summary and supplier performance tables used for the report and presentation.

## Task summary
1. Identify critical issues and prioritize containment and supplier actions.
2. Coordinate a cross-functional review and convert decisions into an owned action plan.
3. Analyze lead time, delayed-component on-time delivery, and supplier performance.
4. Present compliance impact, mitigation roadmap, KPIs, and decisions required.

## Review order
1. Open `Prompt_Library/Copilot Prompt Library.docx`.
2. Review Task 1 and Task 2 documents.
3. Review `Supporting_Files/Supply Chain Analysis.xlsx` and the Task 3 report.
4. Open the Task 4 PowerPoint in presentation mode and review the speaker notes.

## Important note
This is a training simulation. Meeting participants and ownership assignments are fictional. Analysis values are based on the supplied project dataset available in the connected project resources.
